# Teacher BJD GLB

Place the production BJD asset at:

```text
web/public/models/teacher-bjd.glb
```

The Three.js renderer loads `/models/teacher-bjd.glb` automatically. The current
checked-in model is `Ball Joint Doll Rigged Basemesh - Male Ver.` by
ChamberSu1996, licensed CC-BY-4.0 from Sketchfab.

If the file is missing, the stage uses the procedural Three.js BJD avatar so the
WebGL path still works.

For direct pose driving, use common rig bone names such as `LeftArm`,
`LeftForeArm`, `RightArm`, `RightForeArm`, `LeftUpLeg`, `LeftLeg`,
`RightUpLeg`, and `RightLeg`.
